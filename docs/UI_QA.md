# v1.1 工作台验证

日期：2026-10-15。独立无登录资料的 Chromium，固定合成数据。只测试现有浅色内容、深色导航主题，不宣称完整 WCAG 合规。

| 检查 | 结果 | 范围 |
| --- | --- | --- |
| 320、375、768、1440 CSS px | pass | 稳定状态截图，页面无横向溢出 |
| 200% 文字放大 | pass | 375px，全元素原计算字号加倍 |
| 文字间距覆盖 | pass | 行高1.5、字距.12em、词距.16em、段距2em |
| 原生键盘入口、可见焦点、减少动态效果 | pass | Tab 聚焦，原生按钮；reduced-motion 模式 |
| 三类筛选与选中详情 | pass | 1 条明确需求、1 条采购机会、2 条待核验；原文与未知信息可读 |
| 创建、暂停恢复、完成、取消、导出 | pass | 本地 SQLite 演示队列及 JSON 下载 |
| 断连、请求失败、无效成功响应 | pass | 拦截本地请求；写入禁用，旧状态明确标示，重试可恢复 |
| 输入、幂等请求标识 | pass | 请求失败保留；本地刷新保留输入，同次失败不更换标识 |
| 60 秒后旧状态 | pass | 浏览器时钟推进，队列动作与取消均禁用 |
| 浏览器脚本错误 | pass | 上述流程无 pageerror |
| 真实研究、外联、真实买家、Safari、屏幕阅读器 | not tested | 不在本轮范围 |

输入仅在当前浏览器会话的 sessionStorage 保留。截图均来自公开合成夹具，未展示真实买家。审查见 [UI_AUDIT.md](UI_AUDIT.md)。
